# Decision-Trees-and-Random-Forests
Implemented Decision Tree and Random Forest models using Scikit-learn for classification. Explored tree visualization, overfitting control, feature importance, model accuracy comparison, and 5-fold cross-validation.


## Objective
Learn and compare tree-based machine learning models for classification.

## Tools & Technologies
- Python
- Scikit-learn
- Pandas
- NumPy
- Matplotlib

## Key Features
- Decision Tree classification and visualization
- Overfitting analysis using tree depth
- Random Forest classification
- Model accuracy comparison
- Feature importance visualization
- 5-fold cross-validation

## Dataset
Breast Cancer Wisconsin dataset from Scikit-learn.

## How to Run
1. Install the required libraries.
2. Run `decision_tree_random_forest.py`.

## Outcome
Compared Decision Tree and Random Forest models and evaluated their performance using accuracy and cross-validation.
